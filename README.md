# Hostel-Campus-Complaint-Bot
Mini project by Sahil Lagad, Roll No. 17, LY CORE 3.    
Hostel and campus complaints can be difficult to organize and prioritize when they are submitted informally. This project provides a simple web application where students submit a complaint, and an LLM classifies its category, urgency, and a short summary. The application assigns a unique complaint ID and stores the complaint for tracking.

## Installation
1. Create and activate a virtual environment.  
2. Install dependencies with pip install -r requirements.txt.   
3. Copy .env.example to .env and set OPENAI_API_KEY.   
4. Run streamlit run app.py
